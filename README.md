# GRC105 Incident Response Planning Assignment

Course: GRC105 Incident Management and Business Continuity, Week 20
Assessment: Incident Response Planning and Ransomware Response Simulation

## About
This repository contains my submission for the Northbridge Skills Institute ransomware case. I act as the Incident Response Lead and complete all six tasks:

1. Incident classification and initial assessment
2. Incident response plan, CSIRT roles and RACI matrix
3. Response playbook and evidence preservation
4. Communication and escalation
5. Tabletop exercise and improvement plan
6. Case study analysis and critical reflection
